# 🎙️ FinVoice AI — Automated Financial Video Generator

> Daily AI-powered financial analysis videos in Turkish & English, fully automated.

## 🚀 What is FinVoice AI?

FinVoice AI is a fully automated, end-to-end financial video production pipeline 
designed for faceless YouTube channels. Every day, after market close, the system:

- 📊 Pulls real-time market data (stocks, crypto, forex, commodities)
- 📈 Generates professional candlestick charts with technical indicators (RSI, MACD, MA)
- 🤖 Writes analysis scripts using large language models
- 🎙️ Converts scripts into natural voiceovers using ElevenLabs AI
- 🎬 Produces ready-to-publish videos automatically with FFmpeg

🛠️ Tech Stack
Data: yfinance (Yahoo Finance API)
Charts: matplotlib / plotly (dark theme candlestick charts)
AI Scripts: LLM-powered financial analysis writing
Voice: ElevenLabs API (Turkish & English professional voices)
Video: FFmpeg (rendering, transitions, text overlays)
Scheduler: Daily automated pipeline (post market close)
💡 Why FinVoice AI?
Retail investors in Turkey and emerging markets lack access to high-quality, daily, data-driven financial video content in their native language. FinVoice AI makes it possible to produce broadcast-quality financial journalism at zero marginal cost per video — fully automated, every single day.
